REVEAL VARIANTS · 006 A · Twine + crest B · Pen + crest C · Twine + ticket Same sequence in all three; only the thread and the die change. Columns and the floor are common.

Variant ATwine, tied to the pins · crest stamped in a ring

Heavy two-strand twine, wrapped round each pin head. It goes on slack, the crest slams down, and only then does the string pull taut. A broken link gets NO LINK in red and the string parts.

Variant BRed felt-tip · crest stamped in a ring

The scout draws the line by hand. Same stamp; the connective is a marker stroke with a hand's wobble, and a broken link gets a scrawled cross through it.

Variant CTwine · LINKED ticket stamp

Same twine as A. The die is a rectangular form stamp — the word first, the club under it, crest small — so the row reads as a document that has been through an office.
Replay buttons on each variant: Held is the good path (6th of 16 and 14th of 16). Broken snaps the middle link. Jackpot lands the right-hand slot on 1 — the gold moment.
